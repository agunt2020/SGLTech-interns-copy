# SGLTech-interns — House Rules

Welcome! This is a **private** repo for SGL Tech interns to upload and track project work. A few ground rules to keep it clean and secure.

## Security

- **Never commit secrets** — no API keys, passwords, tokens, `.env` files, or credentials. Need a secret? Ask Frank; don't put it in the repo.
- **No client data** — do not upload real client or customer data, files, or PII.
- Committed something sensitive by accident? Tell Frank right away.

## Workflow

- Work on **your own branch** (e.g. `apu/ai-chatbot`), not directly on `main`.
- Open a **pull request** when you want your work reviewed or merged.
- Keep your work in your own folder if the repo is shared with other interns.

## Access

- Send Frank your GitHub username so he can add you as a collaborator with Write access.

Questions? Message Frank anytime.
